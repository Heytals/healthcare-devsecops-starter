# Demo checklist

- [ ] Install Checkov and confirm `checkov --version`.
- [ ] Run the scan on `examples/insecure`; capture actual findings.
- [ ] Run the scan on `examples/secure`; inspect all findings and warnings.
- [ ] Push repository to GitHub.
- [ ] Open Actions and capture a successful workflow run.
- [ ] If demonstrating a failing CI run, use a temporary branch and a controlled test change.
- [ ] Revert test changes.
- [ ] Do not run `terraform apply` for this classroom prototype.
- [ ] Do not use real patient data or commit credentials.
